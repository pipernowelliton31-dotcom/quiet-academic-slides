# Usage prompts and expected behavior

- **“给我做一个8页关于联邦学习的科研PPT，用 Quiet Academic Slides 风格。”** Input is topic, scope, reference style. Research factual claims if needed, organize meaningful mechanism/architecture, deliver editable PPTX and verify all pages.
- **“把我上传的课题组汇报改成上次 From Noise to Image 那套视觉语言，公式和内容不要变。”** Input is an existing PPTX; preserve facts, equations and necessary structure while redesigning. Do not merely paint background ivory.
- **“做个结果汇报：数据在CSV，结合我的论文图，10分钟。”** Start from verified tables and figures; choose charts/results composition; no invented results.
- **“I want a polished 12-slide research talk in the same elegant editorial feel; no watercolor necessary.”** Use paper/ink/style system, varied layouts and true research imagery; watercolor is not compulsory.
- **“把三张图片和一个推导组合成一页学术示意图。”** Solve scientific information topology first, render an editable slide, then inspect at full size.

Always produce a deck with evidence-backed visuals, stable fonts, and exact technical meaning. Never use the reference images as ready-made backgrounds unless the user explicitly chooses them for their own topic and rights are appropriate.
